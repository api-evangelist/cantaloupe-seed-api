# Cantaloupe — Seed API

> Cantaloupe, Inc. (Malvern, PA) runs the Seed platform for unattended retail:
> cashless card readers, micro markets, smart stores and the Seed vending
> management cloud. The Seed API connects a third-party point-of-sale to
> Cantaloupe's cashless gateway and reporting cloud. IMPORTANT FOR AGENTS:
> Cantaloupe publishes NO API reference, NO OpenAPI/AsyncAPI/GraphQL contract,
> NO SDKs and NO MCP server. Access is arranged through a sales form and
> credentials are issued per customer. Do not attempt to construct calls from
> this file — there is no public contract to ground them in.
>
> Generated by API Evangelist (https://apievangelist.com) from its independent
> third-party profile at https://github.com/api-evangelist/cantaloupe-seed-api.
> Not published by Cantaloupe. Last verified 2026-09-06.

## Product

- [Seed API](https://www.cantaloupe.com/products/integrations/seed-api/): Connect an existing POS to Cantaloupe's cloud for cashless processing (debit/credit, mobile and digital wallets, NFC), consolidated billing across vending / micro markets / office coffee, and real-time sales reporting. Marketing page with a lead form; no technical reference.
- [Seed Live](https://www.cantaloupe.com/products/software/seed-live/): Device management included with a Cantaloupe card reader.
- [Seed Pro](https://www.cantaloupe.com/products/software/seed-pro/): Vending management system.
- [Payment processing](https://www.cantaloupe.com/products/integrations/payment-processing/): Cantaloupe as the single gateway for major card brands and wallets.

## Access and authentication

- No public developer portal, no API keys self-service, no sandbox. Access begins at the contact form on the Seed API page.
- Observed 2026-09-06: `GET https://api.mycantaloupe.com/Reports/Run` returns `401` with `WWW-Authenticate: Basic realm="Cantaloupe"`. A control path on the same host returns 404, so the route is real and protected by HTTP Basic. Credentials are issued by Cantaloupe to a Seed Office tenant.
- Observed 2026-09-06: `https://api.seedlive.com/` is an AWS API Gateway returning `403 MissingAuthenticationTokenException` on every path.
- No OAuth 2.0 or OpenID Connect surface: `/.well-known/oauth-authorization-server` and `/.well-known/openid-configuration` 404 on every Cantaloupe host.
